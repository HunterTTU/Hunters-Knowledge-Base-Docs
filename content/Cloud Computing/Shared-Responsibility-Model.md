## What is the Shared Responsibility Model?

The Shared Responsibility Model explains how security responsibilities are divided between the cloud provider and the customer. Cloud providers secure the infrastructure, while customers are responsible for protecting their applications, user accounts, and stored data.

This model helps organizations understand that moving to the cloud does not eliminate the need for cybersecurity.

## Customer Responsibilities

- Protect user accounts
- Secure applications
- Manage permissions
- Encrypt sensitive data
- Configure cloud services properly

## Why is it Important?

Knowing where security responsibilities begin and end helps prevent security gaps and reduces the likelihood of data breaches.

> Cloud security is a partnership between the provider and the customer.
