
## What Is Wireshark?

Wireshark is a free network protocol analyzer that captures and displays network traffic in real time. It is widely used by network administrators, cybersecurity professionals, and students who want to understand how data moves across a network. By examining packets, users can troubleshoot network problems, identify suspicious activity, and learn how communication protocols operate. ### Common Uses

Wireshark can be used in many different situations! A lot of beginners use Wireshark to better understand how devices communicate across a network! Making it a great tool for students like myself.

- Troubleshooting network issues
- Monitoring traffic
- Learning networking concepts
- Investigating security incidents

> Wireshark helps users understand exactly what is happening on a network. 

Because Wireshark captures network traffic, it is commonly used together with [[Firewalls]] to investigate suspicious connections or identify blocked traffic. Organizations also rely on secure technologies such as [[VPN]] connections to protect the network traffic that Wireshark analyzes.
