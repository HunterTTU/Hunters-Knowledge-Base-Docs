# Security Tools

This section contains information about several common cybersecurity tools used to protect computers, networks, and user accounts. Each page explains what the tool is, why it is important, and how it helps improve overall security.

## Topics

- [[Firewalls]]
- [[Antivirus]]
- [[Password Managers]]
- [[VPN]]
- [[Wireshark]]

Cybersecurity is strongest when multiple tools work together. Firewalls help protect networks, antivirus software detects malicious programs, VPNs secure internet connections, password managers protect user accounts, and Wireshark helps analyze network traffic.
